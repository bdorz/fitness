# APP 更新錯誤代碼

設定頁會保留最近一次更新錯誤的代碼、排除建議與簡短技術資訊。回報問題時請一併提供錯誤代碼。

| 錯誤代碼  | 類別         | 常見原因                          | 建議處理                             |
| --------- | ------------ | --------------------------------- | ------------------------------------ |
| `UPD-001` | 平台         | 在非 Android 裝置使用 APP 內更新  | 改從 GitHub Releases 手動下載        |
| `UPD-101` | 檢查版本     | 無法連線至 GitHub API             | 切換網路，關閉 VPN 或私人 DNS        |
| `UPD-102` | 檢查版本     | GitHub API 回傳非成功 HTTP 狀態   | 稍後重試並檢查 GitHub 狀態           |
| `UPD-103` | 檢查版本     | GitHub 回應格式無法解析           | 稍後重試並回報技術資訊               |
| `UPD-104` | Release      | Repository 尚無正式 Release       | 確認 GitHub Releases 是否已發布      |
| `UPD-105` | Release      | 最新 Release 沒有 APK             | 確認 Release Assets 包含 `.apk`      |
| `UPD-201` | 下載         | APK 網址或檔名無效                | 重新檢查更新                         |
| `UPD-202` | 下載         | 網路、Socket 或資料流中斷         | 使用穩定網路；APP 會自動續傳最多三次 |
| `UPD-203` | 下載         | APK 伺服器回傳非成功 HTTP 狀態    | 稍後重試或改用瀏覽器下載             |
| `UPD-204` | 下載完整性   | 檔案大小或 SHA-256 與記錄不一致   | 檢查網路及儲存空間後重試             |
| `UPD-205` | 手機儲存空間 | 無法建立、寫入或移動快取檔案      | 釋放儲存空間或清除 APP 快取          |
| `UPD-206` | 系統下載     | Android DownloadManager 下載失敗  | 檢查系統下載通知、網路及剩餘空間     |
| `UPD-207` | 儲存權限     | Android 9 以下未允許儲存空間權限  | 到系統設定允許權限後重試             |
| `UPD-301` | 安裝         | Android 阻擋或無法啟動 APK 安裝器 | 允許此 APP 安裝未知來源應用程式      |
| `UPD-999` | 未知         | 未分類的更新錯誤                  | 重新啟動 APP，並提供代碼與技術資訊   |

## 下載機制

- Android 10 以上改由系統 `DownloadManager` 下載，與手機瀏覽器使用相同的背景下載服務。
- 系統可在短暫斷線後繼續下載，且 APP 切到背景時不會中止傳輸。
- Android 9 以下會先詢問儲存空間權限，再將 APK 寫入下載目錄。
- 不會在啟動安裝器後立刻刪檔，避免 Android 尚未讀完 APK 就發生剖析失敗。
